# Math Function Scratchpad
I constantly need to tinker with Mathematical functions,
see what the output of a function may be, but really don't want to have to create a NodeJS or Python project every time, so I made this, it's a simple function runner where you can enter a mathematical function and mess with the values.  
It probably already exists, but I think mine is cooler.  
  
All the programming was done by me, but the UI was done with Claude. I don't have the taste to make a nice UI.  
  
It's just an HTML website, all the code is done in vanilla JS.  
Functions are stored in Local Storage.
